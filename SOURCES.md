# Official references

Checked November 5, 2026. ChatGPT features, menus, availability, and permissions can change. NAVI's checklist and templates are independent workflow guidance, not product features promised by these references.

- [Use ChatGPT](https://learn.chatgpt.com/docs/use-chatgpt): natural-language requests, file attachments, projects, supported connections, and reviewing outputs.
- [Projects and chats](https://learn.chatgpt.com/docs/projects): grouping related chats, files, and instructions; a ChatGPT project alone does not expose a computer folder.
- [Email workflow example](https://learn.chatgpt.com/use-cases/manage-your-inbox): connecting supported email tools in ChatGPT Work and separately configuring scheduled reviews.

The basic NAVI route uses supplied documents and manual recordkeeping. Connected editing and recurring tasks require the relevant capabilities in the user's account and appropriate authorization. Check actual tool access rather than assuming it from a guide.
