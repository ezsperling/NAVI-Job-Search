# NAVI roadmap

This roadmap describes proposed work. It does not create integrations, background tasks, or product commitments.

## Current toolkit

- Beginner setup guide and ChatGPT project instructions.
- Application standard with 18 checklist items.
- Copyable requests and private record templates.
- Blank CSV tracker and formatting guidance.
- Fictional walkthrough and project case study.

## Next: validate the guided workflow

| Priority | Proposed work | Completion evidence |
| --- | --- | --- |
| 1 | Walk through one fictional application | Record preparation, review, receipt reconciliation, gaps, and next action |
| 2 | Check common failure cases | Preserve unknown salary/state eligibility; distinguish drafts, alerts, and submissions |
| 3 | Check duplicate matching | Update one application by company/requisition; retain separate roles at the same company |
| 4 | Check record recovery | Keep unsupported dates blank and label candidate reports |
| 5 | Try setup with a new user | Note confusing instructions, blocked steps, and requested improvements |

The repository's fictional walkthrough supplies a demonstration, not proof of a completed live user trial.

## Later: improve usability

Consider a formatted spreadsheet template, a shorter quick-start handout, clearer interview preparation examples, and a private activity-log template. Evaluate each against an actual user need before expanding the toolkit.

## Potential commercial direction

Possible options to evaluate include guided setup, tracker customization, and tailored application-workflow support. Pricing, packaging, licensing, and launch decisions remain undecided. This roadmap does not promise automated applications or hiring outcomes.

Keep customer records and business plans private. Review which reusable materials should remain public before publishing future commercial assets.

## Separate infrastructure work

A custom server, API key, OAuth application, automatic discovery service, or scheduler is not required for this toolkit. Any future software implementation needs its own scope, capability checks, and validation.

## Measures to collect before making claims

Record setup completion, user-reported friction, correctly matched application updates, missing-evidence handling, and recovery from blocked access. Collect any timing measurements consistently and report sample size. Do not claim a change caused more interviews without adequate evidence.
