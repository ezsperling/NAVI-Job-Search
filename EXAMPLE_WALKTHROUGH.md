# Walk through one application with NAVI

**Fictional demonstration.** Morgan Lee, Harbor Example Health, job DEMO-104, all messages, dates, and filenames below are invented. This is not a real opening, candidate record, or report of an application NAVI submitted. No private account access is needed.

Read [START_HERE](START_HERE.md) for setup and use the [application standard](NAVI_APPLICATION_STANDARD.md) for real applications.

## 1. Start with a profile and posting

**Example candidate:** Morgan wants remote healthcare operations analyst roles, is based in Texas, and seeks at least $100,000 annual base pay. Morgan has verified experience producing Excel reports and coordinating escalations. Morgan has completed SQL coursework but has not used SQL in a production job.

**Example posting:** Harbor Example Health, Healthcare Operations Analyst, DEMO-104. It lists US remote work, $95,000–$115,000 annual base pay, Excel reporting, and cross-functional coordination. SQL is preferred. Eligible states are not specified.

Ask ChatGPT:

> Compare this example posting with Morgan's profile using NAVI. Separate proven experience, transferable experience, and gaps. Keep missing facts unknown. Do not create a real application or search for this fictional employer.

Expected assessment:

| Check | Evidence-based conclusion |
| --- | --- |
| Excel and coordination | Supported fit from the fictional profile |
| SQL | Coursework only; do not claim professional SQL experience |
| Pay | Range overlaps the candidate's target; an acceptable offer is not guaranteed |
| Texas eligibility | Unconfirmed; US remote alone is insufficient |
| Priority | Worth clarifying eligibility and reviewing the complete requirements |

For a real role, verify the opening through the official employer careers site and preserve the complete dated posting. This demo cannot satisfy that verification.

## 2. Prepare, without recording an application as submitted

Create one private role folder and a record using [Application_Record.md](Application_Record.md). Check the existing tracker before adding a row.

A truthful draft bullet could read:

> Produced Excel reporting and coordinated escalation follow-up across operational teams.

Do not add percentages, dollar savings, managerial authority, or production SQL experience absent from the candidate's evidence.

In this example, the resume and cover letter are drafts. The tracker stage is **Preparing**, Date Applied stays blank, and Next Action is **Morgan: confirm Texas eligibility before deciding whether to apply**.

## 3. Review the actual form

Suppose the form parses Morgan's previous employer as a current employer. Correct it before submission and verify the dates against the approved resume.

Ask Morgan to answer unknown eligibility or logistical questions. A draft answer does not establish work authorization, equipment availability, or a license.

Preserve exact final answers and attachment versions. Assess whether a deck adds value; this fictional role uses no deck.

## 6. Handle the next message

- A job alert does not change the application stage.
- A role-specific interview invitation supports Interviewing and a new next action.
- A rejection for a different requisition does not close DEMO-104.
- Silence alone does not support Rejected.

For real use, keep the candidate's records private. This example can be read without entering any personal data.
